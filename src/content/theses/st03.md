## Research question

Can a short-horizon reference governor reduce safety violations while preserving task performance for a nominal reaching controller?

## Minimum scope

Build a self-contained Python simulation of a point-mass or kinematic reaching task, a nominal controller and a reference-level governor. Predict a clearly defined obstacle margin and modify unsafe references; specify model and tracking assumptions. No existing robot-specific pipeline, work from other projects, hardware or ROS is required.

## Evaluation

Compare nominal control, passive monitoring and the governor over reproducible scenarios; report minimum distance, violations, intervention, task error, completion and computation time. Clearly distinguish empirical behavior from guarantees.

## Prerequisites

Python, control or optimization, basic kinematics and simulation.

## Expected deliverables

Simulation, nominal and governor baselines, documented interface and assumptions, scripts, plots and thesis report.

## First Iteration

**Objective:** Show how a reference governor can modify a proposed movement before it approaches an obstacle.

**Task:**

Create a minimal reference-governor prototype for a simple reaching task.

Use a simple point-mass or kinematic model. A nominal reference or target should be given. The governor should decide whether the reference can be accepted directly or whether it should be modified because the predicted motion would approach an obstacle too closely.

The first iteration should show:
- a nominal reference that would lead to a near-critical or unsafe motion,
- a modified reference generated by the governor,
- a plot of nominal reference, modified reference, obstacle, and resulting trajectory,
- a simple status output such as `pass`, `warn`, or `modify`.

The prototype does not need to use a humanoid simulator yet.

**Deliverables:** Provide the runnable script, the reference and trajectory plot, and a brief description of the model and decision logic.

**Evaluation criteria:** Assess whether the unsafe reference and modification are clear, the decision is reproducible, and the model limitations are explained.
