## Research question

How does the integration of robot-state information, environmental perception, and execution feedback affect the reliability of natural-language task planning and execution?

## Minimum scope

### Background and objective

Natural language interfaces provide an intuitive way for humans to interact with autonomous robots. However, translating spoken instructions into reliable robot behavior requires more than simple command recognition. A robot must interpret user intentions, consider its current state and environment, select appropriate capabilities, and monitor task execution.

Develop and evaluate a **local, language-driven task planning and execution framework** for a mobile robot in a ROS 2 and Gazebo simulation environment.

A locally deployed Small Language Model (SLM) will be used to interpret natural-language instructions and translate them into structured robot tasks. The system should support German and English, including text and spoken interaction.

The robot should be able to execute navigation tasks, perform predefined manipulation actions, answer questions about its surroundings, and provide feedback on ongoing operations.

Example interactions include:

- "Drive to the entrance and then return home."
- "What can you see around you?"
- "Is there an obstacle on your right?"
- "Do you see a person or a chair?"
- "Go to the inspection station and wave."
- "Stop the current task and return to the starting position."

Ambiguous or incomplete instructions should be handled through appropriate clarification questions.

### Proposed tasks

1. **Natural Language Interface:** Develop a local SLM-based interface supporting text and speech input in German and English. Translate natural-language instructions into structured robot actions.
2. **Robot Capability Integration:** Connect the language interface to existing ROS 2 components, including navigation through Nav2, predefined arm and gripper movements, and robot status monitoring.
3. **Environment-Aware Interaction:** Integrate environmental information from LiDAR sensors and available object detection systems (e.g., YOLO). Enable the robot to answer questions about nearby obstacles, free directions, and recognized objects.
4. **Task Planning and Execution:** Implement the interpretation and execution of multi-step instructions involving navigation, perception, and predefined manipulation skills. Include action validation, execution monitoring, cancellation, and basic failure handling.
5. **Interactive Dialogue:** Support contextual interactions and clarification questions when instructions are ambiguous, incomplete, or cannot be executed.
6. **Experimental Evaluation:** Design reproducible simulation experiments to evaluate task execution reliability, robustness, and system performance.

The work should build on existing robot navigation, perception, and control components. The focus is on task-level intelligence and interaction rather than the development of new low-level controllers.

## Evaluation

The thesis investigates how environmental context and execution feedback can improve the reliability of language-guided robotic task planning.

Compare different approaches, such as:

- **Direct language-to-action translation:** Generation of robot actions from natural-language instructions.
- **Context-aware task planning:** Incorporation of available robot capabilities, environmental information, and current robot state.
- **Feedback-based execution:** Monitoring of task progress and handling of execution failures through recovery actions or clarification dialogues.

Relevant evaluation metrics include task success rate, command interpretation accuracy, invalid-action rate, execution and response latency, and robustness across different formulations and languages.

## Prerequisites

Keywords: ROS 2, Gazebo, Language Models, Task Planning, Human-Robot Interaction, Autonomous Robots.

## Expected deliverables

- A modular ROS 2 framework for local natural-language robot interaction.
- Integration with a mobile robot in Gazebo, including navigation, sensor queries, and predefined manipulation actions.
- Support for German and English text and speech interaction.
- Demonstrations of multi-step task execution, environmental queries, and interactive clarification.
- A reproducible benchmark with quantitative evaluation of the developed approaches.
- Documented source code, experimental results, and analysis.

## First Iteration

**Objective:** Develop a small standalone prototype demonstrating how a locally running language model can interpret natural-language instructions and translate them into valid, structured robot actions using a predefined set of robot capabilities and environmental information.

**Task:** Implement a Python application using a locally executable SLM (e.g., through Ollama).

Define a simplified robot environment containing:

- Three named locations (e.g., entrance, workstation, charging station).
- A set of supported actions, such as `navigate`, `wave`, `stop`, `get_status`, and `describe_surroundings`.
- Example sensor information, including nearby obstacles and detected objects.

The application should accept text instructions in German and English and convert them into structured actions (e.g., JSON).

It should demonstrate:

- Interpretation of individual robot commands.
- Generation of action sequences for multi-step tasks.
- Responses to simple questions about the environment.
- Handling of unknown locations, unsupported commands, or ambiguous instructions.

ROS 2 and Gazebo integration are not required for this initial task.

**Deliverables:**

- Executable Python prototype and short README.
- Definition of the supported robot actions and their parameters.
- At least 12 test instructions in German and English, including expected and generated outputs.
- Brief analysis of interpretation accuracy, errors, and limitations.

**Evaluation criteria:** Compare the generated actions with manually defined expected results. In particular, verify that the system does not generate unsupported actions, unknown destinations, or environmental information that is not provided.
